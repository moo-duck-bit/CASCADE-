문서 세트를 고칠 때 다음 규칙을 따릅니다.
1. 요구사항(Req)이 바뀌면 MDDR에서 같은 Req 번호의 설계 항목을 검토합니다.
2. MDSR 6절 보안 항목 표와 XXCS의 '해당 요구사항'에서 그 Req가 연결된 보안 항목을 검토합니다. 연결되어 있어도 변경 내용과 무관한 항목이면 수정하지 않습니다.
3. 같은 값이 연결 표시 없이 다른 절(3.4절 보안 개요, 다른 Req 등)에 쓰여 있을 수 있습니다. 같은 사실을 가리키면 함께 고치고, 숫자만 같고 다른 사실이면 고치지 않습니다.
4. 보안 항목의 적용 여부는 제품 사이버보안 속성과 첨부3 적용 예외 규칙으로 정해집니다.
   - password_auth(아이디·비밀번호 인증 사용)가 true이면 IA-05, IA-06은 적용, false이면 N/A (첨부3 IA-05 적용 예외: 비밀번호 인증 미사용 기기)
   - stores_pii(개인식별정보 저장)가 false이면 DC-02는 N/A, true이면 적용 (첨부3 DC-02 적용 예외: 보건의료정보를 저장하지 않는 기기)
   - session_termination(세션 종료 기능 제공)이 true이면 UC-03은 적용, false이면 N/A (첨부3 UC-03 적용 예외: 세션 종료 기능이 없는 기기)
   - samd(독립형 소프트웨어 의료기기)가 true이면 SI-10, SI-11은 N/A, false이면 적용 (첨부3 SI-10, SI-11 적용 예외: 소프트웨어 기반 의료기기)
   속성이 바뀌면 해당 보안 항목의 적용 여부와 그에 따라 달라지는 칸을 고치고, 다른 속성이 정하는 항목은 건드리지 않습니다.

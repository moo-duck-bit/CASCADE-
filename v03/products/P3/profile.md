# P3 성인 금연 코치 (사양 카드, 아직 생성하지 않음)

- 제품: 성인 흡연자의 금연을 돕는 디지털 치료기기 소프트웨어. 가상 제품.
- 구성: 모바일 앱, 블루투스 일산화탄소(CO) 측정기, 서버, 상담사·의료진용 대시보드.
- 인증: 휴대폰 인증번호(일회용 코드) 로그인. 비밀번호 없음 → password_auth=false로 시작.
- 저장 정보: 휴대폰 번호, 흡연량·갈망 기록, CO 측정값. 개인식별정보 저장 → stores_pii=true.
- 기기 연동: 블루투스 측정기 페어링·측정값 수신 → ble_device=true.
- 사이버보안 속성 후보: password_auth=false, otp_auth=true, stores_pii=true, ble_device=true, session_termination, samd, remote_update. 측정기가 있으므로 samd 값과 SI-10·SI-11 적용 여부는 생성 전에 정한다.
- 사실 예: 인증번호 유효 시간, 인증번호 재요청 제한 횟수, CO 측정 주기, 측정기 페어링 유지 시간, 갈망 기록 알림 시각, 금연 프로그램 기간, 세션 종료 시간, 감사로그 보관 기간 등.
- 요구사항 규모: P1과 같게.
- 생성 모델: 가능하면 Qwen 계열이 아닌 모델.
